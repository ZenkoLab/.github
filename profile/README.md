# ZenkoLab

Outil d'aide au diagnostic en ophtalmologie par intelligence artificielle.

ZenkoLab analyse les rétinographies et les OCT pour détecter précocement certaines pathologies oculaires et prioriser les cas urgents. L'objectif est de ramener le délai de diagnostic de 18 jours à moins d'une minute.

## Pathologies détectées

| Pathologie | Sensibilité |
|:--|:--:|
| Rétinopathie diabétique | 99,6 % |
| DMLA | 98,6 % |
| Glaucome | 89,5 % |

## Conformité

Hébergement de données de santé (HDS), conformité RGPD, serveurs situés en France.
